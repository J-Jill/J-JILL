### Featured project

#### 🌍 [WildSphere](https://wildsphere.netlify.app/) · [Repository](https://github.com/J-Jill/wildsphere)

> A high-performance 3D biodiversity visualizer mapping real-time species data onto an interactive globe.

- Built with **React**, **TypeScript**, **Three.js (R3F)** and the live **iNaturalist API**
- Geographic-to-Cartesian coordinate conversion for accurate globe projection
- Optimized for 60 FPS using frame-loop animations and App Shell architecture to decouple UI from the 3D render layer
- Fully responsive and accessible
